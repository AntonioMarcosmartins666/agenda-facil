# 📅 Agenda Fácil

![Agenda Fácil](./ChatGPT%20Image%2023%20de%20set.%20de%202026%2C%2023_22_53.png)

## Plataforma de Gestão de Agendamentos

O **Agenda Fácil** é uma aplicação web desenvolvida para facilitar o gerenciamento de agendamentos, clientes e serviços em um único lugar.

O projeto foi desenvolvido com foco em uma experiência simples, organizada, responsiva e adequada para uso em diferentes dispositivos.

## 🌐 Acessar a aplicação

👉 **[Abrir o Agenda Fácil](https://agenda-facil-black.vercel.app/)**

## ✨ Principais recursos

- 📅 Gerenciamento de agendamentos
- 👥 Cadastro e gerenciamento de clientes
- ⚙️ Organização de serviços
- 📊 Visualização e organização da agenda
- 🔐 Fluxo de autenticação
- 📱 Interface responsiva
- 💾 Integração com Supabase
- 🌐 Aplicação publicada em produção

## 🛠️ Tecnologias utilizadas

- **React**
- **TypeScript**
- **Vite**
- **Supabase**
- **PostgreSQL**
- **HTML**
- **CSS**
- **JavaScript**
