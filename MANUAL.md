# 📘 Manual de Uso — Agenda Fácil

## 📅 Sobre o Agenda Fácil

O **Agenda Fácil** é uma aplicação web desenvolvida para facilitar o gerenciamento de agendamentos e clientes.

A plataforma permite organizar compromissos, cadastrar clientes e acompanhar a rotina de atendimentos de forma simples e centralizada.

## 🚀 Como utilizar

### 1. Acessar o sistema

Abra a aplicação no navegador:

https://agenda-facil-black.vercel.app/

Na tela inicial, faça login utilizando sua conta.

Após entrar, você será direcionado para o painel principal.

## 📊 2. Painel principal

O painel apresenta uma visão geral da sua agenda.

A partir dele é possível acessar as principais áreas do sistema:

- 📅 Agendamentos
- 👥 Clientes
- ⚙️ Serviços
- 📈 Informações da agenda
- 🔐 Configurações

## 📅 3. Criar um agendamento

Para criar um novo agendamento:

1. Acesse **Agendamentos**.
2. Clique em **Novo agendamento**.
3. Selecione o cliente.
4. Escolha o serviço.
5. Informe a data.
6. Informe o horário.
7. Confira as informações.
8. Salve o agendamento.

## 👥 4. Cadastrar um cliente

Para adicionar um novo cliente:

1. Acesse **Clientes**.
2. Clique em **Novo cliente**.
3. Informe os dados solicitados.
4. Confira as informações.
5. Clique em **Salvar**.

## ✏️ 5. Editar um cliente

Para alterar os dados de um cliente:

1. Acesse **Clientes**.
2. Localize o cliente.
3. Clique na opção de edição.
4. Atualize os dados.
5. Salve as alterações.

## 📋 6. Consultar agendamentos

Na área de **Agendamentos**, é possível consultar informações como:

- Cliente
- Serviço
- Data
- Horário
- Status

## ❌ 7. Cancelar um agendamento

Para cancelar um agendamento:

1. Acesse **Agendamentos**.
2. Localize o compromisso.
3. Selecione a opção de cancelamento.
4. Confirme a operação.

## ⚙️ 8. Gerenciar serviços

Para adicionar um serviço:

1. Acesse **Serviços**.
2. Clique em **Novo serviço**.
3. Informe o nome e os dados solicitados.
4. Confira as informações.
5. Clique em **Salvar**.

## 🔎 9. Organização da agenda

Para manter a agenda organizada:

- Confira os horários antes de criar um compromisso.
- Mantenha os dados dos clientes atualizados.
- Mantenha os serviços cadastrados corretamente.
- Atualize ou cancele compromissos quando necessário.
- Consulte regularmente a agenda.

## 🔐 10. Segurança

Para proteger sua conta:

- Não compartilhe sua senha.
- Utilize uma senha segura.
- Faça logout ao utilizar computadores compartilhados ou públicos.

## 📱 11. Acesso pelo celular

O Agenda Fácil possui uma interface responsiva, permitindo sua utilização em:

- 💻 Computadores
- 📱 Celulares
- 📲 Tablets
